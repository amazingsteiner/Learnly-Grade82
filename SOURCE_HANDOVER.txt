13. UI PROBLEMS
==========================================================

Current UI has serious usability problems.

Observed:

- Some text is too small.
- Some buttons are too large.
- Some buttons are disproportionate.
- Some controls go outside the visible Android/Pydroid screen.
- Screens are not consistently responsive.
- The app does not yet feel like a polished educational application.

Do NOT simply increase every font/button size globally.

The UI needs responsive sizing.

Target:

- Comfortable body text
- Larger headings
- Medium buttons
- Compact secondary controls
- Scrollable content
- No horizontal overflow
- No buttons cut off
- No giant button grids
- Consistent margins
- Touch-friendly controls
- Clear hierarchy

Suggested baseline:

Body:
    ~16 px

Small secondary:
    ~14 px

Heading:
    ~22 px

Page title:
    ~28 px

Primary action:
    ~50–58 px height

Secondary action:
    ~42–48 px height

Avoid excessive 64+ px buttons unless they are major actions.

Use:

QScrollArea
QSizePolicy
layout stretch factors
responsive grids
minimum/maximum widths

Long questions should wrap.

Long topic lists should scroll.

==========================================================

Use deterministic local logic.

Examples:

IF mastery < 40:
    recommend foundation guide

IF mastery 40–60:
    recommend guided practice

IF mastery 60–75:
    recommend standard practice

IF mastery 75–90:
    recommend advanced practice

IF mastery > 90:
    recommend elite challenge

IF repeated mistakes:
    recommend explanation + worked example

IF accuracy high but speed low:
    recommend speed drill

IF speed high but accuracy low:
    recommend slower conceptual practice

IF student repeatedly requests hints:
    recommend Guide

IF strong:
    increase difficulty
