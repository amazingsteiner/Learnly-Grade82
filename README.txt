LEARNLY — PYSIDE6 FOUNDATION
============================

This is the first modular PySide6 foundation for Learnly.

RUN
---
Open main.py in Pydroid 3.

The project is deliberately split into:
- main.py
- engine/
- ui/
- screens/
- content/
- data/

CURRENT FOUNDATION
------------------
- PySide6 application shell
- Student-code login
- Local student JSON profile
- Five themes
- Home dashboard
- Learn screen
- Practice screen
- Question Papers screen
- Profile screen
- Settings screen
- Tutor Mode entry
- Scrollable layouts
- Relative/project-based data folders
- External curriculum JSON
- External techniques JSON
